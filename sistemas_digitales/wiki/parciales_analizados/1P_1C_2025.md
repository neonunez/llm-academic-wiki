## Ejercicio 1 — Truncado hexadecimal y flags de ALU 4-bit

### Enunciado

Dados los numerales hexadecimales de 8 bits A=E8, B=7B, C=5C:

1. Aplicar truncado a 4 bits (eliminar los 4 MSB) y completar tabla: numeral en bits, valor sin signo, valor en CA2.
2. Calcular A+B, A-C, B-C con flags CVZN de ALU 4-bit (mostrar cuentas).

### Resolucion

**Paso 1 — Conversion hex→bin y truncado:**

$$A = (E8)_{16} = (1110\ 1000)_2 \xrightarrow{\text{trunc}(4)} (1000)_2$$
$$B = (7B)_{16} = (0111\ 1011)_2 \xrightarrow{\text{trunc}(4)} (1011)_2$$
$$C = (5C)_{16} = (0101\ 1100)_2 \xrightarrow{\text{trunc}(4)} (1100)_2$$

**Paso 2 — Tabla:**

| | Bits (4) | Sin signo | CA2 |
|---|---|---|---|
| A | 1000 | 8 | -8 |
| B | 1011 | 11 | -5 |
| C | 1100 | 12 | -4 |

CA2 para numeros con MSB=1: $-8 + \text{(valor de los 3 LSB)}$
- A: $-8 + 0 = -8$
- B: $-8 + 3 = -5$
- C: $-8 + 4 = -4$

**Paso 3 — Operaciones ALU:**

*A + B:*
```
  1000   (A = -8 en CA2)
+ 1011   (B = -5 en CA2)
------
  0011   = 3
carry: 1 (carry final)
```
| Flag | Valor | Justificacion |
|------|-------|---------------|
| C | 1 | quedo carry al final |
| V | 1 | sume dos negativos y obtuve positivo → overflow |
| Z | 0 | resultado ≠ 0 |
| N | 0 | MSB del resultado = 0 (positivo) |

*A - C = A + (~C+1):*
$$\sim C = \sim 1100 = 0011 \quad \Rightarrow \quad \sim C + 1 = 0100$$
```
  1000   (A)
+ 0100   (~C+1)
------
  1100   = -4 en CA2
carry: 0 al sumar, pero hay borrow → C=1 (NOT carry)
```
| Flag | Valor | Justificacion |
|------|-------|---------------|
| C | 1 | hubo borrow (C en resta = NOT carry de la suma) |
| V | 0 | signos de operandos originales eran distintos (A neg, C neg... ambos negativos pero resultado negativo → sin overflow) |
| Z | 0 | resultado ≠ 0 |
| N | 1 | MSB = 1 (negativo) |

*B - C = B + (~C+1):*
```
  1011   (B = -5)
+ 0100   (~C+1)
------
  1111   = -1 en CA2
```
| Flag | Valor | Justificacion |
|------|-------|---------------|
| C | 1 | hubo borrow |
| V | 0 | signos distintos para operandos relativos |
| Z | 0 | resultado ≠ 0 |
| N | 1 | MSB = 1 (negativo) |

### Explicacion

El ejercicio combina tres conceptos de representacion_de_informacion:
1. **Cambio de base** hex→bin
2. **Truncado**: tomar los n bits menos significativos (los n MSB se descartan)
3. **Tabla de flags CVZN** de una ALU:
   - **C (Carry/Borrow):** en suma = carry del bit 4; en resta = NOT del carry (si hay borrow, C=1)
   - **V (Overflow):** sume dos del mismo signo y obtuve del signo opuesto
   - **Z (Zero):** resultado == 0
   - **N (Negative):** MSB del resultado == 1

### Analisis de la resolucion

Resolucion correcta. El corrector anoto ¡PERFECTO!

Detalle sutil sobre el flag C en restas: el parcial lo define como C=1 si hubo borrow (convension "NOT carry"). Esto es coherente con la implementacion en hardware donde A-C = A + ~C + 1 y el carry de salida se invierte para obtener el borrow.

Para el overflow en A-C: ambos operandos truncados son negativos (-8 y -4), el resultado es -4 (negativo) → no hay overflow (el overflow ocurre cuando el resultado "escapa" al rango de representacion con signo). V=0 correcto.

### Chuleta

> 1. Hex→bin: expandir cada digito a 4 bits
> 2. Truncar a k bits: tomar los k LSB
> 3. Sin signo: valor posicional directo
> 4. CA2 con MSB=1: $-2^{k-1} + \text{(valor de los k-1 LSB)}$
> 5. Suma binaria: alinear, propagar carry
> 6. Resta: convertir en suma con complemento ($A - B = A + \sim B + 1$)
> 7. Flags: C=carry final (resta: NOT carry), V=desbordamiento de signo, Z=resultado es 0, N=MSB del resultado

## Ejercicio 2 — Logica Combinatoria: SDP y circuito

### Enunciado

Funcion booleana F(A,B,C) definida por tabla de verdad:

| A | B | C | F |
|---|---|---|---|
| 0 | 0 | 0 | 1 |
| 0 | 0 | 1 | 1 |
| 0 | 1 | 0 | 0 |
| 0 | 1 | 1 | 0 |
| 1 | 0 | 0 | 0 |
| 1 | 0 | 1 | 1 |
| 1 | 1 | 0 | 0 |
| 1 | 1 | 1 | 1 |

1. Escribir la suma de productos (SDP) y contar compuertas de la implementacion literal.
2. Implementar con **unicamente** compuertas AND/OR de 2 entradas y NOR. Indicar cantidad de compuertas.

### Resolucion

**Parte 1 — SDP canonica:**

Minterminos con F=1: $m_0$(000), $m_1$(001), $m_5$(101), $m_7$(111)

$$F = \bar{A}\bar{B}\bar{C} + \bar{A}\bar{B}C + A\bar{B}C + ABC$$

Compuertas literales (sin optimizar):
- 6 NOT (una por variable negada en cada termino)
- 4 AND de 3 entradas
- 3 OR (para 4 terminos se necesitan 3 OR de 2 entradas)
- **Total: 13 compuertas** (con AND/OR de 2 entradas: mas aun)

**Parte 2 — Simplificacion algebraica:**

$$\bar{A}\bar{B}\bar{C} + \bar{A}\bar{B}C + A\bar{B}C + ABC$$
$$= \bar{A}\bar{B}(\bar{C}+C) + AC(\bar{B}+B) \quad \text{(Distributiva + Conmutativa)}$$
$$= \bar{A}\bar{B}\cdot 1 + AC\cdot 1 \quad \text{(Complemento)}$$
$$= \bar{A}\bar{B} + AC$$
$$= \overline{A+B} + AC \quad \text{(De Morgan: } \bar{A}\bar{B} = \overline{A+B}\text{)}$$

Circuito (3 compuertas):
```
A, B → [NOR] ──────────────────→ [OR] → F
A, C → [AND] ─────────────────↗
```
- 1 NOR + 1 AND + 1 OR = **3 compuertas**

### Explicacion

El ejercicio evalua dos habilidades:
1. **SDP canonica:** identificar minterminos (filas F=1) y escribir el producto de literales para cada uno
2. **Simplificacion algebraica:** aplicar distributiva, De Morgan, complemento para minimizar compuertas

El truco de De Morgan es fundamental: $\bar{A}\bar{B} = \overline{A+B}$, lo que permite usar directamente una NOR para obtener ese termino.

### Analisis de la resolucion

La simplificacion algebraica es correcta y bien justificada (cada paso nombra el axioma usado). El circuito final de 3 compuertas es optimo.

Nota: el alumno primero calculo 13 compuertas para la SDP literal (correcto), y luego redujo a 3 con simplificacion (correcto).

### Chuleta

> 1. SDP: para cada fila F=1, escribir el producto de todas las variables (negadas si valen 0)
> 2. Contar compuertas literales: NOT por literal negada + AND por termino + OR entre terminos
> 3. Simplificar: buscar pares con una sola variable que difiere (absorbcion) → factorizar
> 4. De Morgan: $\bar{A}\bar{B} = \overline{A+B}$ → NOR; $\bar{A}+\bar{B} = \overline{A\cdot B}$ → NAND
> 5. Con NOR: calcular De Morgan inverso para convertir suma-de-productos a NOR-AND-OR

## Ejercicio 3 — Logica Secuencial: Flip-flops D

### Enunciado

Circuito con 3 flip-flops tipo D (Q0, Q1, Q2) con reset, todos conectados al mismo clock (no dibujado). En el instante $t_0$: Q0=1, Q1=0, Q2=0.

Completar la tabla de estados hasta encontrar un ciclo que se repita (o demostrar que no es posible).

### Resolucion

**Reglas de transicion (leidas del circuito):**
$$Q_0' = Q_2, \quad Q_1' = Q_0, \quad Q_2' = Q_1$$

Es un **registro de desplazamiento circular** de 3 bits (cada bit se mueve al FF siguiente, el ultimo vuelve al primero).

**Tabla de estados:**

| ciclo | Q0 | Q1 | Q2 |
|-------|----|----|-----|
| $t_0$ | 1  | 0  | 0   |
| $t_1$ | 0  | 1  | 0   |
| $t_2$ | 0  | 0  | 1   |
| $t_3$ | 1  | 0  | 0   |  ← igual a $t_0$

**Conclusion:** el estado en $t_3$ es igual al estado en $t_0$ → ciclo de periodo 3 (el alumno lo describe como "bucle infinito de tamaño 4" contando los 4 instantes $t_0$...$t_3$).

### Explicacion

El circuito es un **registro de desplazamiento circular** (ring shift register):
- En cada flanco de clock, el bit en Q_i se copia en Q_{i+1 mod 3}
- Con estado inicial (1,0,0), el "1" circula: Q0→Q1→Q2→Q0→...
- El periodo es 3 (3 estados distintos antes de repetir)

### Analisis de la resolucion

Resolucion correcta. El corrector dio checkmark.

Nota sobre la terminologia: el alumno escribe "bucle infinito de tamaño 4" refiriendose a los 4 instantes $t_0$, $t_1$, $t_2$, $t_3$ (contando el instante de repeticion). El periodo matematico es 3 (cantidad de estados distintos). Ambas descripciones son aceptables.

Nota sobre las funciones de transicion: el alumno escribe $Q_0' = \bar{Q}_2 = Q_2$, lo que sugiere que el D de Q0 se conecta a la salida $\bar{Q}$ de Q2, pero eso contradice la secuencia observada. La secuencia correcta se obtiene con $Q_0' = Q_2$ (salida directa, no complementada). Posible error de notacion del alumno que el corrector no senalo.

### Chuleta

> 1. Leer el circuito: identificar a que salida (Q o Q̄) esta conectado el D de cada FF
> 2. Escribir las funciones de transicion: $Q_i' = f(Q_0, Q_1, Q_2)$
> 3. Calcular estado siguiente fila por fila en la tabla
> 4. Parar cuando el estado actual == algun estado anterior → ese es el inicio del ciclo
> 5. Periodo = distancia entre los dos estados iguales
