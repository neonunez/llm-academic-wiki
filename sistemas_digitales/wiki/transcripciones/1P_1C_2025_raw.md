## Ejercicio 1 — Representacion de la Informacion

*En este ejercicio deberan estar las cuentas que sostengan el resultado final, en caso contrario el resultado sera considerado invalido.*

Dados los siguientes 3 numerales hexadecimales de 8 bits:

- A: E8
- B: 7B
- C: 5C

Definimos **truncado** como la operacion que consiste en eliminar los n bits mas significativos de un numero binario, quedando con los n bits menos significativos.

Utilizando la tecnica de truncado, quedarse con la parte menos significativa para tener numeros de 4 bits y completar la siguiente tabla:

| | Numeral en bits | Valor sin signo | Valor en CA2 |
|---|---|---|---|
| A | 1000 | 8 | -8 |
| B | 1011 | 11 | -5 |
| C | 1100 | 12 | -4 |

Dar el resultado de las siguientes operaciones (realizando las cuentas) e indicar el valor que tendrian los flags de una ALU de 4 bits (CVZN):

| Operacion | Resultado | C | V | Z | N |
|---|---|---|---|---|---|
| A + B | 3 | 1 | 1 | 0 | 0 |
| A - C | -4 | 1 | 0 | 0 | 1 |
| B - C | -1 | 1 | 0 | 0 | 1 |

## Resolucion del alumno — Ejercicio 1 (paginas 1 y 2)

**Conversion hexadecimal a binario y truncado:**

$A = (E8)_{16} = (1110\ 1000)_2$. Luego $\text{trunc}(4, 1110\ 1000) = (1000)_2 = (8)_{10}$ (sin signo)

Para CA2: veo que el bit mas significativo es 1 y entonces es negativo.
Para encontrar el CA2, le sumo los 3 bits menos significativos al minimo representable (-8):
$-8 + (000)_2 = -8$

Mismo metodo para B y C:

$B = (7B)_{16} = (0111\ 1011)_2$. $\text{trunc}(4, 0111\ 1011) = (1011)_2 = 11_{10}$ (sin signo)
Es negativo: $-8 + (011)_2 = -5$ (CA2)

$C = (5C)_{16} = (0101\ 1100)_2$. $\text{trunc}(4, 0101\ 1100) = (1100)_2 = 12_{10}$ (sin signo)
Es negativo: $-8 + (100)_2 = -4$ (CA2)

**SUMO A y B:**
```
  01 10  (carries)
  1000
+ 1011
------
  0011  = (3)_{10}
```
- C=1 pues quedo un carry al final
- V=1 pues sume 2 numeros negativos y obtuve un positivo
- Z=0 pues el resultado no es cero
- N=0 pues el resultado es positivo (bit mas significativo 0)

**RESTO A y C:**

Inverso aditivo de C: $\sim C + 1$
```
  0011
+ 0001
------
  0100  (inverso aditivo de C = 1100)
```

$A - C$:
```
  1000
+ 0100
------
  1100 = (-4)_{10}\ (\text{CA2})
```
- C=1 pues hubo un borrow (NOT carry) [C=0 tachado]
- V=0 pues los signos eran distintos
- Z=0 pues el resultado no es cero
- N=1 pues el resultado es negativo (bit mas significativo 1)

**RESTO B y C:**

Idem con el inverso de C:
```
  1011
+ 0100
------
  1111 = (-1)_{10}\ (\text{CA2})
```
- C=1 pues hubo un borrow (NOT carry) [C=0 tachado]
- V=0 pues los signos eran distintos
- Z=0 pues el resultado no es cero
- N=1 pues el resultado es negativo (idem)

## Ejercicio 2 — Logica Combinatoria

Dada la funcion booleana F definida en la siguiente tabla de verdad:

| A | B | C | F(A,B,C) |
|---|---|---|---------|
| 0 | 0 | 0 | 1       |
| 0 | 0 | 1 | 1       |
| 0 | 1 | 0 | 0       |
| 0 | 1 | 1 | 0       |
| 1 | 0 | 0 | 0       |
| 1 | 0 | 1 | 1       |
| 1 | 1 | 0 | 0       |
| 1 | 1 | 1 | 1       |

1. Escribir la *suma de productos* para la funcion F. Calcular la cantidad de compuertas que la implementacion literal requeriria.

2. Realizar el circuito logico correspondiente a la funcion F utilizando **unicamente** compuertas AND y OR de dos entradas y NOR. Indicar la cantidad de compuertas utilizadas. No es necesario que el circuito este optimizado.

---

## Resolucion del alumno — Ejercicio 2 (pagina 3)

**Parte 1 — SDP:**

"Tomo todas las filas donde F=1, hago el producto de las variables (negandola si vale 0) y luego hago la suma de todos los filas:"

$$(\bar{A}\cdot\bar{B}\cdot\bar{C}) + (\bar{A}\cdot\bar{B}\cdot C) + (A\cdot\bar{B}\cdot C) + (A\cdot B\cdot C)$$

Conteo de compuertas literal:
- 6 NOT
- 4 AND de 3 entradas
- 3 OR
- Total: 13 compuertas

Nota del alumno: "SOLO SE DEBEN USAR COMPUERTAS DE 2 ENTRADAS" (aclaracion para la parte 2)

**Parte 2 — Simplificacion algebraica:**

$$(\bar{A}\cdot\bar{B}\cdot\bar{C}) + (\bar{A}\cdot\bar{B}\cdot C) + (A\cdot\bar{B}\cdot C) + (A\cdot B\cdot C) \quad \text{(Distributiva)}$$
$$= (\bar{A}\cdot\bar{B})\cdot(\bar{C}+C) + (\bar{A}\cdot C\cdot\bar{B}) + (A\cdot B\cdot C) \quad \text{(Conmutativa x2)}$$
$$= (\bar{A}\cdot\bar{B})\cdot(\bar{C}+C) + (A\cdot C\cdot\bar{B}) + (A\cdot C\cdot\bar{B}) \quad \text{(Nulo)}$$
$$= (\bar{A}\cdot\bar{B})\cdot 1 + (A\cdot C\cdot\bar{B}) + (A\cdot C\cdot\bar{B}) \quad \text{(Distributiva)}$$
$$= (\bar{A}\cdot\bar{B})\cdot 1 + (A\cdot C)\cdot(\bar{B} + B) \quad \text{(Nulo)}$$
$$= (\bar{A}\cdot\bar{B})\cdot 1 + (A\cdot C)\cdot 1 \quad \text{(Neutro x2)}$$
$$= (\bar{A}\cdot\bar{B}) + (A\cdot C) \quad \text{(De Morgan)}$$
$$= \overline{(A+B)} + (A\cdot C) = (A \downarrow B) + (A \cdot C)$$

Circuito resultante: A, B → **NOR** → OR ← **AND** ← A, C → F(A,B,C)

Conteo: 1 NOR + 1 AND + 1 OR = **3 compuertas**

Anotacion del corrector: checkmark (correcto)
