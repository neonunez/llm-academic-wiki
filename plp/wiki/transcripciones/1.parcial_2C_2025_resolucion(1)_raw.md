Ejercicio 1 - Programación funcional
Aclaración: en este ejercicio no está permitido utilizar recursión explícita.
El siguiente tipo de datos sirve para representar un sistema de archivos sin enlaces lógicos (FS por su sigla en inglés). Un sistema de archivos puede entenderse como un árbol de subdirectorios y archivos.
data FS = Arch String | Dir String [FS] deriving (Eq, Show)
Donde Arch nombre representa el archivo con nombre nombre, y Dir nombre contenido representa el directorio llamado nombre que contiene los archivos y subdirectorios de la lista contenido.
unDir = Dir "raiz" [Arch "arch1", Arch "arch2", Arch "arch3", Dir "subdir1" [Arch "arch4"], Dir "subdir2" [Arch "arch1", Arch "arch5"]]

a) Dar el tipo y definir las funciones foldFS y recFS, que implementan respectivamente los esquemas de recursión estructural y primitiva para el tipo FS. Solo en este inciso se permite usar recursión explícita.
Ayuda: recFS :: ... -> (String -> [FS] -> [a] -> a) -> ...

b) Definir la función rutas :: FS -> [String], que lista las rutas de todos los archivos y subdirectorios de un sistema de archivos dado, usando la barra "/" como separador de directorios.

c) Definir la función valido :: FS -> Bool, que indique si, para cada directorio de un sistema de archivos, todos sus archivos y subdirectorios tienen nombres distintos. No importa si hay nombres repetidos entre distintos niveles. Sugerencia: usar all y nub.

d) Definir la función rutasPosibles :: [String] -> [String], que dada una lista de nombres (sin repetidos) genera la lista (infinita) de todas las rutas no vacías que se pueden generar con esos nombres.
El código debe tener la estructura (a completar):
rutasPosibles xss = concatMap ... [0..]
  where ... = foldNat (\rs -> [s1++'/'++s2 | ...]) ...
Con foldNat::(b->b)->b->Integer->b definido en la guía.

a)
foldFS :: (String -> sol) -> (String -> [sol] -> sol) -> FS -> sol
foldFS fArch fDir fs = case fs of
  (Arch s) -> fArch s
  (Dir s subfss) -> fDir s (map (foldFS fArch fDir) subfss)

recFS :: (String -> sol) -> (String -> [FS] -> [sol] -> sol) -> FS -> sol
recFS fArch fDir fs = case fs of
  (Arch s) -> fArch s
  (Dir s subfss) -> fDir s subfss (map (recFS fArch fDir) subfss)

rutas :: FS -> [String]
rutas = foldFS (\s -> [s]) (\s subs -> s : (map (\ruta -> s ++ "/" ++ ruta) (concat subs)))

## Page 5 (Resolución Ejercicio 2 Parte 1)
a) 
P(t) = forall c::a . forall n::Int . tamaño (truncar c t n) <= tamaño t
Inducción estructural sobre t.
- Probar P(Hoja x)
- Probar (P(i) ^ P(d)) => P(Dos x i d)
- Probar (P(i) ^ P(m) ^ P(d)) => P(Tres x y i m d)

Caso Hoja x: lado izquierdo de P(Hoja x):
tamaño (truncar c (Hoja x) n) = tamaño (const (Hoja c) n) = tamaño ((\y -> Hoja c) n) = tamaño (Hoja c) = 1.
Por otro lado, el lado derecho es tamaño (Hoja x). Por lema, 1 <= tamaño (Hoja x).
Por tanto, 1 = tamaño (truncar c (Hoja x) n) <= tamaño (Hoja x). Vale.

## Page 6 (Resolución Ejercicio 2 Parte 2)
Caso Dos x i d:
tamaño (truncar c (Dos x i d) n)
= tamaño ((\n -> if n<1 then (Hoja c) else (Dos x (truncar c i (n-1)) (truncar c d (n-1)))) n)
= tamaño (if n<1 then (Hoja c) else (Dos x (truncar c i (n-1)) (truncar c d (n-1))))
Caso (n<1) = True:
tamaño (Hoja c) = 1. Por lema, 1 <= tamaño (Dos x i d). Vale.
Caso (n<1) = False:
tamaño (Dos x (truncar c i (n-1)) (truncar c d (n-1)))
= 1 + tamaño (truncar c i (n-1)) + tamaño (truncar c d (n-1))
Por HI en i y d:
tamaño (truncar c i (n-1)) <= tamaño i
tamaño (truncar c d (n-1)) <= tamaño d
Sumando 1 y ambas inecuaciones:
1 + tamaño (...) + tamaño (...) <= 1 + tamaño i + tamaño d = tamaño (Dos x i d)
Lado izquierdo <= lado derecho. Vale.

## Page 7 (Resolución Ejercicio 2 Deducción Natural)
b) Deducción Natural de: ((pi => rho) v (sigma => tau)) => (sigma ^ pi) => (rho v tau)
(La derivación en árbol muestra cómo de `(sigma ^ pi)` se extrae `sigma` y `pi`. Y abriendo la disyunción Gamma con dos casos: `pi => rho` y `sigma => tau`. 
Si `pi => rho`, se obtiene `rho` aplicando a `pi` que sacamos de la conjunción. Luego se introduce `rho v tau`. 
Si `sigma => tau`, se obtiene `tau` de manera análoga, y se introduce `rho v tau`. 
Por eliminación de la disyunción inicial, se llega a `rho v tau` en todos los casos, concluyendo en el resultado implicado).
Nota: "Bien!" escrita por el profesor.
