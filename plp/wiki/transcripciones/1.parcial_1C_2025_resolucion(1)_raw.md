data ABNV a = Hoja a | Uni a (ABNV a) | Bi (ABNV a) a (ABNV a)

abnv = Bi (Uni 2 (Hoja 1)) 3 (Bi (Hoja 4) 5 (Uni 2 (Hoja 7)))

## Pages 3, 4 (Resolución Ejercicio 1)
a)
foldABNV :: (a -> b) -> (a -> b -> b) -> (b -> a -> b -> b) -> ABNV a -> b
foldABNV fHoja fUni fBi ab = case ab of
  Hoja v -> fHoja v
  Uni v ar -> fUni v (rec ar)
  Bi i v d -> fBi (rec i) v (rec d)
  where rec = foldABNV fHoja fUni fBi

recABNV :: (a -> b) -> (a -> ABNV a -> b -> b) -> (ABNV a -> b -> a -> ABNV a -> b -> b) -> ABNV a -> b
recABNV fHoja fUni fBi ab = case ab of
  Hoja v -> fHoja v
  Uni v ar -> fUni v ar (rec ar)
  Bi i v d -> fBi i (rec i) v d (rec d)
  where rec = recABNV fHoja fUni fBi

b)
elemABNV :: Eq a => a -> ABNV a -> Bool
elemABNV e = foldABNV (\v -> v == e) (\v rec -> (v == e) || rec) (\reci v recd -> (v == e) || reci || recd)

c)
reemplazarUno :: Eq a => a -> a -> ABNV a -> ABNV a
reemplazarUno x y = recABNV 
  (\v -> if (x == v) then (Hoja y) else (Hoja v))
  (\v ar rec -> if (x == v) then (Uni y ar) else (Uni v rec))
  (\i reci v d recd -> if (x == v) then (Bi i y d) else if (elemABNV x i) then (Bi reci v d) else (Bi i v recd))

d)
nivel :: ABNV a -> Int -> [a]
nivel = foldABNV
  (\v -> (\n -> if (n == 0) then [v] else []))
  (\v rec -> (\n -> if (n == 0) then [v] else rec (n-1)))
  (\reci v recd -> (\n -> if (n == 0) then [v] else reci (n-1) ++ recd (n-1)))

b) Deducción Natural
Queremos probar: p => (sigma v (p => tau)) => (sigma v tau)
Asumimos p.
Asumimos (sigma v (p => tau)).
Para eliminar el Or (sigma v (p => tau)):
- Caso sigma: Asumo sigma. Luego introduzco Or: sigma v tau.
- Caso p => tau: Asumo p => tau. Como tengo p, por Modus Ponens obtengo tau. Luego introduzco Or: sigma v tau.
En ambos casos llego a sigma v tau.
Descargo asunciones con intro => y termino.

a) Inducción Estructural en AB a.
Qvq forall t::AB a . P(t) vale.
P(t) = forall x::a. forall f::a->b . (elemAB x t => elemAB (f x) (mapAB f t))

Caso Base P(Nil):
elemAB x Nil => elemAB (f x) (mapAB f Nil)
Lado izquierdo: elemAB x Nil = False.
False => A es verdadero. P(Nil) vale.

Paso Inductivo P(Bin i r d):
HI: P(i) y P(d) valen.
elemAB x (Bin i r d) => elemAB (f x) (mapAB f (Bin i r d))
Asumo verdadero el antecedente (si es falso, la implicación es trivial).
elemAB x (Bin i r d) = (x == r) || elemAB x i || elemAB x d.
Por lema de generación de Bool, hay 3 casos donde esto es True:
Caso A) x == r es True.
Por regla de congruencia, f x == f r.
Lado derecho: elemAB (f x) (Bin (mapAB f i) (f r) (mapAB f d))
= (f x == f r) || ... = True || ... = True. Vale.
Caso B.A) elemAB x i es True.
Por HI en i: elemAB (f x) (mapAB f i) es True.
Lado derecho evalúa a ... || True || ... = True. Vale.
Caso B.B) elemAB x d es True.
Por HI en d: elemAB (f x) (mapAB f d) es True.
Lado derecho evalúa a ... || True = True. Vale.
