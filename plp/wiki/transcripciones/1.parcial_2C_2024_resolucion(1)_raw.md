## Page 3 (Resolución Ejercicio 1)
data Buffer a = Empty | Write Int a (Buffer a) | Read Int (Buffer a)

a) 
foldBuffer :: b -> (Int -> a -> b -> b) -> (Int -> b -> b) -> Buffer a -> b
foldBuffer cEmpty cWrite cRead t = case t of
  Empty -> cEmpty
  Write n x b -> cWrite n x (rec b)
  Read n b -> cRead n (rec b)
  where rec = foldBuffer cEmpty cWrite cRead

recBuffer :: b -> (Int -> a -> Buffer a -> b -> b) -> (Int -> Buffer a -> b -> b) -> Buffer a -> b
recBuffer cEmpty cWrite cRead t = case t of
  Empty -> cEmpty
  Write n x b -> cWrite n x b (rec b)
  Read n b -> cRead n b (rec b)
  where rec = recBuffer cEmpty cWrite cRead

b) posicionesOcupadas :: Buffer a -> [Int]
posicionesOcupadas = foldBuffer [] 
  (\n _ rec -> union [n] rec)
  (\n rec -> filter (not . (== n)) rec)  -- (escrito como filter rec (\e -> e /= n) pero se entiende)

c) contenido :: Int -> Buffer a -> Maybe a
contenido e = foldBuffer Nothing 
  (\n x rec -> if n == e then Just x else rec)
  (\n rec -> if n == e then Nothing else rec)

d) puedeCompletarLecturas :: Buffer a -> Bool
puedeCompletarLecturas = recBuffer True 
  (\_ _ _ rec -> rec)
  (\n b rec -> (elem n (posicionesOcupadas b)) && rec)

e) deshacer :: Buffer a -> Int -> Buffer a
deshacer = recBuffer (const Empty) 
  (\n x b rec -> \e -> if e == 0 then (Write n x b) else rec (e-1))
  (\n b rec -> \e -> if e == 0 then (Read n b) else rec (e-1))

## Page 4 (Resolución Ejercicio 2a)
a) Prop a demostrar P(t): forall u::AB a . altura t >= altura (zipAB t u)
Por inducción en t.
Caso base P(Nil):
altura Nil >= altura (zipAB Nil u)
0 >= altura (const Nil u)  {Z0}
0 >= altura Nil  {const}
0 >= 0  {A0}
Demostrado P(Nil).

Caso inductivo P(Bin i r d). HI: P(i) ^ P(d)
altura (Bin i r d) >= altura (zipAB (Bin i r d) u)
1 + max (altura i) (altura d) >= altura (zipAB (Bin i r d) u)  {A1}
Por extensionalidad en u: u = Nil o u = Bin x y z.
Caso u = Nil:
1 + max (altura i) (altura d) >= altura (zipAB (Bin i r d) Nil)
1 + max (altura i) (altura d) >= altura Nil  {Z1 + Beta}
1 + max (altura i) (altura d) >= 0  {A0}
Por lema, (altura i) >= 0 y (altura d) >= 0. Luego, max (altura i) (altura d) >= 0.
1 + max >= 1 >= 0. Demostrado.

Caso u = Bin x y z:
1 + max (altura i) (altura d) >= altura (zipAB (Bin i r d) (Bin x y z))
1 + max (altura i) (altura d) >= altura (Bin (zipAB i x) (r, y) (zipAB d z))  {Z1 + Beta}
1 + max (altura i) (altura d) >= 1 + max (altura (zipAB i x)) (altura (zipAB d z))  {A1}
Separo el max en 2 casos: max (altura i) (altura d) = altura i   o   max (altura i) (altura d) = altura d
Caso 1: max (...) = altura i. Entonces altura i >= altura d.
altura i >= max (altura (zipAB i x)) (altura (zipAB d z))
Por HI en i: altura i >= altura (zipAB i x).
Por HI en d y que altura i >= altura d: altura i >= altura (zipAB d z).
Luego, altura i >= max (altura (zipAB i x)) (altura (zipAB d z)). Demostrado.
Caso 2: max (...) = altura d. Análogo, usando la HI en d que altura d >= altura (zipAB d z) y en i que altura d >= altura i >= altura (zipAB i x).
Demostrado P(Bin i r d).
