# Salida para guia de ejercicios

## Objetivo pedagogico

Convertir una guia extensa en un plan progresivo de entrenamiento: adquirir, consolidar, alcanzar
dificultad de parcial y detectar variantes redundantes. Resolver 🔴 y 🟡; conservar y justificar
todos los demas ejercicios sin hacerlos desaparecer.
