# Salida para clase practica

## Objetivo pedagogico

Ensenar tecnicas mediante ejercicios modelo. El estudiante debe aprender a reconocer el patron,
decidir un enfoque, ejecutar una solucion razonada, verificarla y transferirla a ejercicios nuevos.
La teoria aparece solo como recordatorio operativo.

Resolver los ejercicios 🔴 y 🟡. Listar brevemente ⚪ y 🆕.
